ไม่มีฟอร์มติดต่อ ปุ่ม LINE และการเก็บสถิติการกด (ต้องใช้ token) · โหมดนำเสนอ (เว็บจริง) ยังว่าง เพราะยังไม่มีแถวไหนติ๊ก 🔒

ลิงก์ตัวอย่างมีเฉพาะหน้า Body Map · ตัวแปลงเว็บทั้งชุดขึ้น Cloudflare ของ repo นี้ติดข้อผิดพลาดเดิมที่ส่วนรับฟอร์ม Explorer ต้องแก้ก่อนขึ้นเว็บจริง

วิธีสร้าง token ของ Airtable ไนน์ทำ ประมาณ 5 นาที

token คือกุญแจให้เว็บอ่านและเขียน Airtable ได้เอง ห้ามวางในแชทหรือส่งให้ใคร ใส่ในไฟล์บนเครื่องเท่านั้น

  1. เปิด airtable.com/create/tokens แล้วกด Create new token
  2. ตั้งชื่อ bib-platform-bodymap
  3. ช่อง Scopes กด Add a scope เลือก 3 ตัว: data.records:read · data.records:write · schema.bases:read
  4. ช่อง Access กด Add a base เลือกฐานของ BIB (รหัส app2HcsMi1mmqTLJi) ฐานเดียว
  5. กด Create token แล้วกด Copy (Airtable แสดงครั้งเดียว)
  6. ในโฟลเดอร์ bib-platform สร้างไฟล์ชื่อ .env.local ใส่ 2 บรรทัด:
    AIRTABLE_TOKEN=วางตรงนี้
    AIRTABLE_BASE_ID=app2HcsMi1mmqTLJi
  7. บันทึกไฟล์ แล้วบอก Claude ว่า "ใส่ token แล้ว" (ไม่ต้องบอกค่า)

ไฟล์ .env.local ถูกตั้งไม่ให้เข้า git อยู่แล้ว · ตอนขึ้นเว็บจริงต้องใส่ค่าเดียวกันใน Cloudflare อีกที่หนึ่ง จะพาทำตอนนั้น

เนื้อหา สำคัญที่สุด · ทำครบ ไม่ตัดทอน

รอไนน์ตอบ "OK เนื้อหา" กับตัวอย่างรอบ 2 ก่อนเขียนทั้งหมด · เขียนเสร็จลง Airtable สถานะ "ร่าง" ทุกแถว

กติกาเสียงที่ใช้: คำที่หมอและคู่มือใช้จริง · ใช้คำว่า "น้ำเหลือง" ตามคู่มือ · ไม่ตั้งคำใหม่ · ประโยคที่ไม่มีหลักฐานตัดทั้งประโยค
