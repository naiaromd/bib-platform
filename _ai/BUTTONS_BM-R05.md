## API
| เส้นทาง | ทำอะไร | ทดสอบ (ไม่มี token) | ผล |
|---|---|---|---|
| POST /api/bodymap-event | เขียน event เป็นชุดลง Body Map Events | 503 "รอ token" | ตรวจแล้ว · เขียนจริงยังไม่ได้ตรวจ |
| POST /api/bodymap-lead | เขียน Web Leads + ผูก event | 400 เมื่อขาดยินยอม/ช่องบังคับ · 503 "รอ token" · honeypot ตอบ ok ไม่เขียน | ตรวจแล้ว · เขียนจริงยังไม่ได้ตรวจ |
| POST /api/line-notify | ให้ automation ส่งข้อความเข้ากลุ่ม LINE ทีม | 401 เมื่อไม่มี secret | ตรวจแล้ว · ส่ง LINE จริงยังไม่ได้ตรวจ (ไม่มี token) |
| POST /api/line-webhook | รับ webhook LINE · ผูก userId กับลีด | — | ยังไม่ได้ตรวจ (ไม่มี channel secret) |
